# 실시간 주식 데이터 시각화 및 모니터링

📌 프로젝트 진행 기간: 2026.07.01 ~ 2026.08.14

📌 프로젝트 참여 인원: 우수하

# 프로젝트 목적
- 본 프로젝트는 GKE(Google Kubernetes Engine) 환경을 기반으로 Websocket을 통해 실시간 데이터를 공급 받아 Kafka와 Spark를 활용해 InfluxDB에 저장하는
실시간 데이터 처리 파이프라인을 구축하는 것을 목표로 합니다.

- InfluxDB와 Grafana를 연동하여 실시간 주식 데이터의 시각화 및 시스템 모니터링 환경까지 통합 구축을 목표로 합니다.
